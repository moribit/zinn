# Code of Conduct

Everyone participating in this project is expected to be respectful, patient and constructive. Welcome people with different backgrounds and levels of experience. Critique code and evidence rather than people; make room for questions and acknowledge corrections.

Harassment, discrimination, threats, personal attacks, sexualized attention and publication of another person's private information are not acceptable. Do not retaliate against someone for raising a concern in good faith.

Maintainers may edit/remove inappropriate contributions, limit interactions, or exclude participants according to the seriousness/repetition of conduct. Apply these expectations consistently, including to maintainers. This policy covers project-controlled issues, pull requests, discussions and other official project spaces.

For non-sensitive moderation concerns, ask maintainers for moderation in the affected repository thread. Do not publish private details in that thread. No private conduct-reporting address is configured in this repository; do not assume an issue or security form is confidential. Maintainers should publish an explicit private contact before inviting sensitive conduct reports. If GitHub-hosted content violates platform rules, use GitHub's reporting mechanisms. Do not send conduct reports to an invented address.
